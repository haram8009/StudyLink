# StudyLink 화면 개선·검증 기록

작성일: 2026-10-22 (Asia/Seoul)

## 변경

사용자 요청으로 Impeccable의 기존 화면 다듬기 흐름을 적용했다. 기존 초록색·밝은 배경과 제품 기능을 유지했다. 실제 제품 코드는 `D:/SSAFY/studylink`에 있고 `streamlit_lab`은 기획 기록이다.

- 홈의 영문 보조 제목과 장식용 종이 그림을 제거하고, 기존 안내 문구와 PDF 자료 → 질문과 답변 → 원문 근거 흐름으로 간결하게 정리했다.
- 공통 CSS의 8~11px 글자를 12~13px로 높이고, 기본 설명·조작 글자는 14px, 답변 본문은 15px로 조정했다. 흐린 보조 글자는 공통 `--muted` 색상으로 통일했다.
- 키보드 포커스, 선택 영역, 스크롤바, 입력 커서, 주요 버튼 44px 높이, 모션 축소 설정을 정리했다.
- 넓은 학습 화면은 채팅 목록 180px·가변 대화·자료 290~340px로 배치한다. 기존 1350px·850px 분기에서 두 열·한 열로 전환한다. 휴대폰에서는 채팅 목록을 가로로 묶고 대화 내부의 중첩 스크롤을 없앴다.
- 긴 원문 발췌는 180px 높이의 스크롤 영역으로 제한해 PDF 열람이 지나치게 밀리지 않게 했다.
- 홈 카드·생성창, 퀴즈·오답노트에도 공통 글자·색상 개선을 적용했다. 데이터·API·검색·저장 방식은 변경하지 않았다.

## 확인 결과

- `frontend`에서 `npm run build` 통과. 500kB 이상 번들 경고는 남아 있으며 이번 화면 변경에서 코드 분할은 하지 않았다.
- 변경한 JSX·CSS 4개에 Impeccable `detect --json`을 한 번 실행해 빈 결과 `[]`를 확인했다. 이후 모바일 안내 흐름 배치·발췌 높이·대화 높이를 추가 조정했다.
- 실제 API로 홈, 기존 대화, PDF 인용의 3페이지 이동, 생성창 진입·닫기, 저장된 퀴즈 채점 결과, 오답 목록 진입을 확인했다. 데이터 생성·수정은 하지 않았다.
- 브라우저의 실제 CSS 너비 390px·1222px·1440px에서 가로 넘침이 없었다. 390px의 홈·대화·퀴즈 결과와 1440px의 세 패널 배치를 렌더링으로 확인했다. 브라우저 확대 설정 때문에 뷰포트 API 요청값과 실제 CSS 너비가 달라 `innerWidth`로 확인했다.
- 확인한 경로에서 브라우저 콘솔 오류가 없었다. 전체 접근성 검사나 모든 오류·로딩 상태 검증을 완료했다는 뜻은 아니다.

## 후속

필요하면 `$impeccable init`으로 제품 맥락을 별도로 정리할 수 있다. 이번 작업은 기존 화면 개선이므로 새 제품 인터뷰나 PRODUCT.md·DESIGN.md 생성은 하지 않았다.
