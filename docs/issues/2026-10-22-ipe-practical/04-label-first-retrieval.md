## What to build

질문에서 "(년도) (회차) (N번)" 패턴을 찾으면 같은 문항 라벨을 가진 청크를 근거에 먼저 넣고, 남은 자리는 기존 임베딩 검색으로 채운다. 우선 근거도 근거 상한에 포함한다. Langfuse trace에 라벨 우선 근거 여부를 남긴다.

## Acceptance criteria

- [ ] "2025년 1회 1번 해설 알려줘" 질문의 근거에 해당 문항 라벨 청크(해설 페이지 포함)가 들어간다
- [ ] 패턴이 없는 질문은 기존 검색 결과와 같다
- [ ] 라벨이 일치하는 청크가 없으면 기존 검색으로 동작하고 오류를 내지 않는다
- [ ] trace에서 우선 근거로 들어간 청크를 구분할 수 있다
