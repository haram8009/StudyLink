## What to build

기본 워크스페이스에서 퀴즈를 만들 때 근거 절을 출제기준 항목 가중치(1+실기 출제 수, 2021-1~2026-2)로 고른다. 코드 분석 3항목(절차적·객체지향·스크립트 언어)에 대응하는 문서는 출제에서 뺀다. 다른 워크스페이스는 기존 추출 방식을 유지한다.

## Acceptance criteria

- [ ] 고정 시드로 여러 번 추출하면 출제 수가 많은 항목의 문서가 더 자주 뽑힌다(분포 테스트)
- [ ] 코드 분석 3항목에만 대응하는 문서는 뽑히지 않는다
- [ ] 태그 없는 텍스트 자료나 다른 워크스페이스에서는 기존 방식으로 동작한다
