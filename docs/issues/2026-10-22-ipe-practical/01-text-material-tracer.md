# 01. 텍스트 자료 최소 경로: 위키 문서 1개를 §절로 인용

유형: AFK · 라벨: `ready-for-agent` · 주담당: B (보조 A·C) · PRD 범위: I02 일부, I03  
상태: 열림 (2026-10-22 작성)

## Parent

[정보처리기사 실기 대비 전환 PRD](../../2026-10-22-02-ipe-practical-prd.md)

## What to build

기본 워크스페이스 "정보처리기사 실기"를 서버 시작 시 멱등하게 만들고, 위키 개념 사전 문서 하나(예: 세션 하이재킹)를 **텍스트 자료**로 넣는다. 절마다 청크를 만들고 위치 번호에 절 번호를 쓴다. 그 공간에서 질문하면 답변 인용이 "문서 제목 §절 제목"으로 보이고, 누르면 해당 절을 펼친 텍스트 뷰어가 열린다. 뷰어에는 원문 URL·판 번호·라이선스를 표시한다. PDF 자료의 기존 동작은 바뀌지 않는다(ADR 0003).

## Acceptance criteria

- [ ] 서버를 두 번 재시작해도 기본 워크스페이스와 텍스트 자료가 하나씩만 있다
- [ ] 텍스트 자료의 청크 위치 번호가 1부터 시작하는 절 번호다
- [ ] "세션 하이재킹이 뭐야?" 답변의 인용에 kind=text와 절 제목이 있고 화면에 "§절 제목"으로 표시된다
- [ ] 인용을 누르면 텍스트 뷰어가 그 절로 열리고 출처 URL·판·라이선스가 보인다
- [ ] 답변을 노트로 저장하면 노트 인용도 같은 절을 가리킨다
- [ ] 기존 PDF 업로드·페이지 인용 테스트가 그대로 통과한다

## Blocked by

None - can start immediately
