## What to build

퀴즈 문항의 근거가 텍스트 자료일 때 문항·해설·오답 상세의 참고 자료를 "문서 제목 §절 제목"으로 표시하고, 누르면 텍스트 뷰어가 그 절로 열린다. 관련 노트 열기는 기존대로 동작한다.

## Acceptance criteria

- [ ] 기본 워크스페이스에서 만든 퀴즈의 참고 자료가 §절로 표시된다
- [ ] 오답 상세에서 절 이동과 관련 노트 열기가 모두 된다
- [ ] PDF 근거 문항은 기존처럼 p.N과 PDF 페이지 이동이 된다
