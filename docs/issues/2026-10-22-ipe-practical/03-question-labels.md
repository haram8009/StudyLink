## What to build

업로드한 PDF는 지금처럼 페이지 단위로 청킹하되, 페이지 텍스트에서 "문제 N"·"N." 문항 시작과 정답·해설 구간을 찾아 청크 앞에 `[파일명 · 문제 N · 해설]` 형태의 **문항 라벨**을 붙인다. 형식을 알아보지 못하면 라벨을 붙이지 않는다. 라벨은 검색 텍스트에 들어가고, 화면 인용문에는 원문만 보인다.

## Acceptance criteria

- [ ] 길벗 회차별 기출 PDF에서 문제 페이지와 해설 페이지에 각각 맞는 문항 번호 라벨이 붙는다
- [ ] 유형별 문제집 PDF("N." 형식)에도 문항 라벨이 붙는다
- [ ] 기존 데모 노트 PDF처럼 형식이 다른 PDF에는 라벨이 붙지 않는다
- [ ] 라벨 규칙은 PDF 원문 없이 짧은 텍스트 표본으로 단위 테스트한다(수험서 원문을 저장소에 두지 않음)
