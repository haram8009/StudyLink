## What to build

퀴즈 설정에 형식(선다형/단답형)을 더한다. 단답형은 설명을 주고 용어를 쓰게 하는 **단답형 문항**이며, 생성 때 **허용 답안**(한글·영문·약어)을 함께 만들고 코드가 비어 있음·중복을 검증한다. 학습자가 답을 입력해 제출하면 공백·대소문자·괄호를 정규화한 뒤 허용 답안과 일치하는지로 채점한다. LLM 채점은 하지 않는다. 문항 수·난이도·요청 개수 충족 규칙은 퀴즈 설정 PRD를 따른다.

## Acceptance criteria

- [ ] 퀴즈 화면에서 형식을 고를 수 있고 기본값은 선다형이다
- [ ] 단답형 문항에는 선택지가 없고 제출 전 정답·허용 답안이 응답에 없다
- [ ] "Session Hijacking", "세션 하이재킹", "세션하이재킹"이 같은 허용 답안 목록이면 모두 정답 처리된다
- [ ] 선다형 퀴즈의 기존 생성·채점 테스트가 그대로 통과한다
- [ ] 오답은 기존처럼 오답노트에 쌓이고 내 답과 허용 답안이 보인다
