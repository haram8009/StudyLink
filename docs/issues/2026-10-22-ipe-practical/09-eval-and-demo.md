# 09. 평가 15문항과 데모 리허설

유형: HITL · 라벨: `ready-for-human` · 주담당: C (전원) · PRD 범위: 6절 인수 기준  
상태: 열림 (2026-10-22 작성)

## Parent

[정보처리기사 실기 대비 전환 PRD](../../2026-10-22-02-ipe-practical-prd.md)

## What to build

위키 개념 질문 6개, 2025년 1회 PDF 질문 4개, 답 없음 5개로 평가 질문셋을 만들고 기존 평가 스크립트로 CSV를 뽑아 사람이 판정한다. 단답형 10문항을 사람이 검토한다. 데모 시나리오 1~5를 재시작 후 두 번 리허설한다. 수험서 기반 질문은 로컬에서만 재현되며 원문은 저장소에 두지 않는다.

## Acceptance criteria

- [ ] 답 있음 10개 중 올바른 위치(절·페이지) 인용 8개 이상, 답 없음 5개 중 보류 4개 이상
- [ ] "N회 N번" 질문 4개 모두 해당 문항 라벨 청크가 근거에 들어간다
- [ ] 단답형 10문항 중 정답·허용 답안 오류 1개 이하, 허용 답안 누락 오답 처리 2개 이하
- [ ] 데모 1~5가 재시작 후 끊김 없이 동작하고 결과를 통합 기록 문서에 남긴다
- [ ] 저장소에 수험서 PDF·문제 원문이 없다
