# 정보처리기사 실기로 도메인을 좁히고, 수험서 PDF는 업로드 자료로만, 위키백과는 내장 텍스트 자료로 쓴다

## Context

StudyLink의 워크스페이스·자료·노트 연결·근거 인용·퀴즈·오답 복귀 흐름은 그대로 두고, 대상 학습을 정보처리기사 실기 대비로 정했다(2026-10-22 사용자 결정). 쓸 수 있는 자료는 두 종류다.

- 길벗(시나공) 실기 수험 PDF 26개(회차별 복원 기출 17개, 신기술·보안 용어 1개, 유형별 문제집 8개). 표지에 "개인 용도만, 복제·전재·상업 이용 금지"가 적혀 있고 시험문제 저작권은 한국산업인력공단에 있다.
- 필기 출제기준 세세항목 174개와 한국어 위키백과 문서의 대응표(직접 94·근사 44·없음 36)와 항목별 실기 출제 수(`backend/seed/ipe-2027-written-kowiki-match.csv`). 위키백과는 CC BY-SA 4.0이다.

어떤 자료를 서비스가 갖고, 어떤 자료를 학습자가 가져오는지에 따라 저장소 내용, 데이터 모델, 외부 전송 범위가 달라진다. 나중에 바꾸려면 재색인과 데이터 이관이 필요하다.

## Decision

- **수험서 PDF는 서비스에 내장하지 않는다.** 학습자가 자기 워크스페이스에 올린 **자료**로만 로컬에서 색인·인용한다. 저장소와 배포물에는 PDF·문제 원문을 두지 않는다(`data/`는 git 제외). 데모는 로컬 비공개로 한다.
- 업로드한 수험서 발췌가 프롬프트로 GMS와 Langfuse 클라우드(JP 리전)에 본문째 기록되는 것을 허용한다. 개인 학습용 비공개 시제품이라는 전제다(2026-10-22 사용자 결정). 마스킹은 구현하지 않는다.
- **위키백과 개념 사전을 내장한다.** 대응표의 직접·근사 대응 문서를 중복 없이 모아, 판 번호(oldid)를 고정한 절 단위 스냅샷으로 저장소에 둔다. 각주·같이 보기·외부 링크 절은 뺀다. 인용할 때 문서 제목·URL·라이선스를 표시한다. 대응이 없는 36개 항목은 비워 둔다.
- 개념 사전은 새 출처 종류가 아니라, 서버가 시작할 때 멱등하게 만드는 기본 워크스페이스 "정보처리기사 실기"의 **자료**다. 다른 워크스페이스에서는 기존처럼 노트 **연결**로 활용한다.
- 위키 문서는 PDF로 바꾸지 않고 **텍스트 자료** 형식으로 넣는다. 인용 단위는 페이지 대신 **절**이다. 위치는 기존 `page` 칸을 "위치 번호"로 재사용해, 텍스트 자료에서는 1부터 시작하는 절 번호를 넣는다.

## Considered Options

- **수험서 PDF를 기본 지식베이스로 미리 색인**: 답변·퀴즈 품질은 가장 좋다. 하지만 이용 조건과 정면으로 충돌하고, 비공개 데모라도 저장소에 원문이 남는다.
- **수험서는 출제 빈도 집계로만 쓰고 원문은 전혀 다루지 않음**: 가장 안전하지만, 학습자가 이미 가진 교재로 "몇 회 몇 번 해설"을 찾는 핵심 사용 장면을 버린다.
- **개념 사전을 모든 워크스페이스에 공통으로 붙는 새 출처 종류로**: 어느 공간에서든 바로 쓰이지만 검색 범위·근거 선택·인용 표시에 세 번째 출처 종류가 생긴다. 1~2일 일정에서 기본 워크스페이스 자료로 두는 편이 변경이 적다.
- **위키를 PDF로 렌더링해 업로드**: 앱 코드 변경이 없지만 페이지 경계가 절과 맞지 않아 인용 위치가 흐려지고, 출처·판 정보가 파일 안에 묻힌다.
- **위치를 `locator_type`+`locator`로 일반화**: 의미는 가장 명확하지만 모든 테이블·API·화면·테스트를 바꿔야 한다.

## Consequences

- documents에 kind(pdf/text)·source_url·revision·license를 더하고, 절 본문을 담는 document_sections를 만든다. 인용·퀴즈·오답 쪽은 `page` 칸을 그대로 쓰고, 화면이 kind를 보고 "p.3"과 "§절 제목"을 구분해 보여준다. 텍스트 자료용 뷰어가 필요하다.
- 위키 스냅샷 재생성은 시드 스크립트로만 한다. 판을 바꾸면 해당 문서를 다시 임베딩한다. CC BY-SA에 따라 스냅샷과 화면에 출처를 남긴다.
- 수험서를 다루는 기능(문항 라벨, "N번" 검색, 문제집 기반 코드 문제)은 학습자가 PDF를 올렸을 때만 동작한다. 평가 질문 중 수험서 기반 문항은 로컬에서만 재현할 수 있다.
- 외부 공개나 다른 사람의 자료를 받게 되면 Langfuse 본문 기록 허용과 수험서 처리 방식을 다시 결정해야 한다.
