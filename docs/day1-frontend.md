# 1일차 프런트 구현 기록

2026-10-21. React 18·Vite·JavaScript와 react-router로 홈·워크스페이스 화면을 구현했다. 기본 API는 FastAPI이며 목 화면은 VITE_USE_MOCK=true로 구분한다.

- 워크스페이스 생성·목록·상세, 자료 업로드·2초 상태 폴링·실패 재시도, 질문 입력·진행 표시·오류 안내를 제공한다.
- 답변 문장에 유효한 답변 인용을 표시하고, 근거 패널에서 자료명·페이지·발췌를 확인한다. PDF 원문을 새 탭으로 여는 링크도 제공한다. PDF를 화면 안에 표시하는 패널과 페이지 이동 완성은 2일차다.
- API 호출은 API 클라이언트로 모았으며 빈 상태·질문 불가 상태·중복 제출 비활성화를 처리한다.
- npm run build가 통과했다. 실제 브라우저에서 워크스페이스 생성·PDF 업로드·질문 흐름을 통합 확인한다. 최종 결과는 [통합 기록](day1-integration.md)을 따른다.

프런트 담당 에이전트가 초기 구현 후 사용량 한도로 중단되어 통합 담당이 빌드·코드 정리·브라우저 점검을 이어받았다.
