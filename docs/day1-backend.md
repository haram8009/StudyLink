# 1일차 백엔드 구현 기록

2026-10-21. FastAPI·SQLite·PyMuPDF로 워크스페이스·자료 API와 질문 서비스 연결을 구현했다.

- SQLite는 전체 시제품 테이블과 조회용 인덱스를 준비했고 WAL·외래 키 검사를 사용한다. 요청과 수집 작업마다 연결을 분리한다.
- 업로드는 processing 응답 후 백그라운드에서 텍스트 추출·페이지별 약 800자 청킹·배치 임베딩을 수행한다. 청크와 ready 상태는 함께 커밋하고 실패 시 청크를 남기지 않는다.
- 반복 머리말·꼬리말과 페이지 번호를 제거한다. 실제 데모 추출 확인 결과는 워드 임베딩 5쪽·5청크, Transformer 11쪽·13청크다.
- 기본 30MB 제한, 텍스트가 거의 없는 페이지가 절반을 넘을 때 스캔 PDF 안내, 원문 PDF inline 제공, failed 자료 재시도, 재시작 processing 복구를 제공한다.
- 루트 .env를 읽으며 GMS_KEY를 우선 사용한다. 목·실제 DB는 분리한다.
- 백엔드 API 테스트 5개가 통과했다. 전체 테스트와 실제 GMS 통합 결과는 [통합 기록](day1-integration.md)을 따른다.

백엔드 담당 에이전트가 핵심 구현 후 사용량 한도로 중단되어 통합 담당이 문서와 실행 검증을 마무리했다.
